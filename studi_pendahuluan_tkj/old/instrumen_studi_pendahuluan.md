## 4. DRAFT TES DIAGNOSTIK AWAL *LOGICAL THINKING* (KUIS PENARAN SINGKAT)

**Tujuan:** Mengukur skor performa riil penalaran logika siswa (sebagai data kuantitatif objektif untuk Bab 1 Latar Belakang).  
**Waktu Pengerjaan:** 15 Menit | **Sifat:** Pilihan Ganda (5 Soal)

---

**Soal 1 (Tracing Variabel SEDERHANA):**  
Diberikan potongan kode berikut:
```python
x = 5
y = 3
x = x + y
y = x - y
print(x, y)
```
Berapakah nilai `x` dan `y` yang tercetak pada layar?  
A. 5 3  
B. 8 3  
C. 8 5  
D. 5 8  

---

**Soal 2 (Tracing Percabangan / Conditionals):**  
Diberikan potongan kode berikut:
```python
skor = 75
if skor >= 80:
    hasil = "A"
elif skor >= 70:
    hasil = "B"
else:
    hasil = "C"
print(hasil)
```
Output apa yang dihasilkan oleh program tersebut?  
A. A  
B. B  
C. C  
D. Error  

---

**Soal 3 (Pattern Recognition & Looping):**  
Diberikan perulangan berikut:
```python
total = 0
for i in range(1, 4):
    total = total + i
print(total)
```
Berapakah nilai akhir variabel `total`?  
A. 3  
B. 4  
C. 6  
D. 10  

---

**Soal 4 (Debugging Logic / Mencari Kesalahan Logika):**  
Seorang siswa ingin membuat program untuk mengecek apakah bilangan $n$ adalah **bilangan genap**. Namun programnya salah:
```python
if n % 2 == 1:
    print("Genap")
else:
    print("Ganjil")
```
Di manakah letak kesalahan logika program tersebut?  
A. Harusnya menggunakan `n / 2 == 0`  
B. Operator sisa bagi genap seharusnya `n % 2 == 0`  
C. Variabel `n` tidak boleh dikali  
D. Perintah `print` harus ditulis dengan huruf kapital  

---

**Soal 5 (Analisis Sebab-Akibat Logika):**  
Jika kondisi `(A DAN B)` bernilai BENAR (TRUE), manakah pernyataan yang PASTI BENAR?  
A. A bernilai SALAH, B bernilai BENAR  
B. A bernilai BENAR, B bernilai SALAH  
C. Baik A maupun B keduanya harus bernilai BENAR  
D. Salah satu dari A atau B boleh bernilai SALAH
