## 4. DRAFT TES DIAGNOSTIK AWAL *LOGICAL THINKING*
### Berbasis Tobin & Capie Framework (1981) - Konteks Jaringan Komputer (TKJ)

* **Sasaran:** Siswa Kelas XI TKJ
* **Waktu:** 20 Menit | **Sifat:** Pilihan Ganda Penalaran Logis (5 Soal)
* **Tujuan:** Menghasilkan data empiris kuantitatif performa *Logical Thinking* siswa untuk latar belakang Bab I.

---

#### Soal 1: Dimensi *Controlling Variables* (Mengontrol Variabel / Isolasi Masalah)
**Indikator:** Kemampuan mengidentifikasi dan mengisolasi variabel penyebab gangguan jaringan secara independen tanpa mengubah parameter lain secara acak.

**Skenario Soal:**  
Sebuah komputer klien (PC-A) di lab TKJ tiba-tiba tidak dapat mengakses web server lokal (`192.168.10.1`), padahal sebelumnya koneksi berjalan normal. Untuk mendiagnosis letak gangguan secara logis dan ilmiah, teknisi jaringan harus menguji komponen satu per satu secara terisolasi. 

Langkah pengujian pertama yang **paling tepat** untuk mengisolasi variabel permasalahan sebelum mengubah pengaturan konfigurasi IP atau router adalah...  
A. Langsung mereset konfigurasi router ke pengaturan pabrik (*default factory*).  
B. Melakukan uji `ping` ke alamat loopback (`127.0.0.1`) dan IP kartu jaringan PC-A sendiri untuk memastikan TCP/IP lokal berfungsi normal.  
C. Mengganti sistem operasi pada PC-A dan memasang ulang kabel jaringan baru.  
D. Mengubah IP address server lokal menjadi satu subnet dengan PC lain secara acak.  

*Kunci Jawaban: B*  
*Rubrik Penalaran:* Menilai apakah siswa mampu mengontrol variabel lokal (tumpukan protokol TCP/IP internal PC) sebelum berspekulasi mengubah variabel eksternal (router/server).

---

#### Soal 2: Dimensi *Combinatorial Reasoning* (Penalaran Kombinatorik)
**Indikator:** Kemampuan merancang dan mengombinasikan pembagian blok subnet (VLSM) secara sistematis tanpa terjadi tumpang tindih (*overlapping*).

**Skenario Soal:**  
Administrator jaringan diberikan satu blok alamat jaringan `192.168.1.0/24`. Ia ditugaskan membagi jaringan tersebut untuk 3 ruangan dengan kebutuhan sebagai berikut:
- Lab 1: Membutuhkan 60 host valid.
- Lab 2: Membutuhkan 28 host valid.
- Ruang Server: Membutuhkan 12 host valid.

Kombinasi alokasi *prefix length* (CIDR) yang **paling efisien dan tidak saling bertabrakan (*overlapping*)** untuk ketiga ruangan tersebut berturut-turut adalah...  
A. Lab 1: `/25`, Lab 2: `/26`, Ruang Server: `/27`  
B. Lab 1: `/26`, Lab 2: `/27`, Ruang Server: `/28`  
C. Lab 1: `/26`, Lab 2: `/26`, Ruang Server: `/26`  
D. Lab 1: `/24`, Lab 2: `/25`, Ruang Server: `/26`  

*Kunci Jawaban: B*  
*Rubrik Penalaran:* 
- Kebutuhan 60 host $\rightarrow$ butuh minimal $2^6 - 2 = 62$ host $\rightarrow$ prefix `/26`.
- Kebutuhan 28 host $\rightarrow$ butuh minimal $2^5 - 2 = 30$ host $\rightarrow$ prefix `/27`.
- Kebutuhan 12 host $\rightarrow$ butuh minimal $2^4 - 2 = 14$ host $\rightarrow$ prefix `/28`.  
Siswa diuji kemampuan menyusun kombinasi partisi ruang alamat secara matematis dan sistematis.

---

#### Soal 3: Dimensi *Proportional Reasoning* (Penalaran Proporsional)
**Indikator:** Kemampuan memahami relasi proporsi matematis eksponensial ($2^{32-n} - 2$) antara nilai prefix CIDR terhadap kapasitas jumlah host valid yang tersedia.

**Skenario Soal:**  
Sebuah link koneksi *point-to-point* yang hanya menghubungkan Router-A dan Router-B secara langsung membutuhkan tepat **2 alamat IP host** (satu untuk masing-masing router). Jika administrator mengalokasikan subnet mask `/24` (254 host valid) untuk link tersebut, terjadi pemborosan alamat IP yang sangat besar. 

Berapakah rasio perbandingan kapasitas host yang **terbuang sia-sia** antara penggunaan prefix `/24` dibandingkan jika administrator menggunakan prefix yang paling proporsional untuk link point-to-point (`/30`)?  
A. Penggunaan `/24` membuang 252 IP, sedangkan `/30` membuang 0 IP (efisiensi 100%).  
B. Penggunaan `/24` membuang 126 IP, sedangkan `/30` membuang 2 IP.  
C. Penggunaan `/24` membuang 254 IP, sedangkan `/30` membuang 4 IP.  
D. Penggunaan `/24` dan `/30` memiliki rasio kapasitas yang sama karena berada dalam kelas C.  

*Kunci Jawaban: A*  
*Rubrik Penalaran:* Menilai pemahaman proporsi efisiensi: prefix `/30` menghasilkan $2^2 - 2 = 2$ host (tepat terpakai 2, terbuang 0 IP), sedangkan prefix `/24` menghasilkan 254 host (terpakai 2, terbuang 252 IP).

---

#### Soal 4: Dimensi *Probabilistic Reasoning* (Penalaran Probabilistik)
**Indikator:** Kemampuan mengevaluasi kemungkinan pemilihan jalur pengiriman data (*routing decision*) berdasarkan metrik probabilitas dan performa link.

**Skenario Soal:**  
Sebuah router memiliki dua alternatif jalur statis untuk mengirimkan data ke kantor pusat:
- **Jalur Utama (Link Fiber):** *Administrative Distance* (AD) = 1, namun riwayat log menunjukkan tingkat *packet loss* fluktuatif mencapai 40% akibat kabel sering terganggu.
- **Jalur Cadangan (Link Wireless):** *Administrative Distance* (AD) = 5, dengan tingkat *packet loss* stabil 0%.

Berdasarkan aturan logika perutean standar (*default routing behavior*), manakah pernyataan yang **pasti terjadi** mengenai probabilitas pengiriman paket data oleh router jika kedua interface link dalam kondisi aktif (*up*)?  
A. Router secara otomatis membagi beban paket 50% ke Jalur Utama dan 50% ke Jalur Cadangan secara bergantian.  
B. Router akan tetap 100% memprioritaskan Jalur Utama karena nilai AD-nya lebih kecil (AD 1 < AD 5), sehingga paket data memiliki probabilitas tinggi mengalami gangguan *packet loss* kecuali dibuatkan mekanisme *failover/netwatch*.  
C. Router secara cerdas langsung mengabaikan Jalur Utama dan memilih Jalur Cadangan tanpa perlu konfigurasi tambahan.  
D. Paket data akan dibuang (*dropped*) oleh router karena bingung memilih dua jalur yang berbeda.  

*Kunci Jawaban: B*  
*Rubrik Penalaran:* Menguji apakah siswa memahami hukum probabilitas keputusan router: router bekerja berbasis metrik/AD deterministik, bukan asumsi intuitif manusia.

---

#### Soal 5: Dimensi *Correlational Reasoning* (Penalaran Korelasional)
**Indikator:** Kemampuan mengidentifikasi hubungan timbal-balik antara kesalahan konfigurasi logis (*subnet mask / gateway*) terhadap pola kode pesan kesalahan jaringan (*troubleshooting feedback*).

**Skenario Soal:**  
Dua orang siswa TKJ mengonfigurasi PC klien:
- **Kasus 1:** Siswa A salah menginput IP *Default Gateway* pada PC (mengarah ke IP yang tidak ada di jaringan). Saat melakukan `ping` ke IP publik Google (`8.8.8.8`), muncul pesan eror: `Request Timed Out` (RTO).
- **Kasus 2:** Siswa B salah mengonfigurasi IP PC klien sehingga tidak satu segmen/subnet dengan router lokalnya. Saat melakukan `ping` ke router, muncul pesan eror: `Destination Host Unreachable` (DHU).

Berdasarkan analisis korelasi logis antara konfigurasi dan jenis pesan eror tersebut, korelasi yang **benar** adalah...  
A. Pesan `Destination Host Unreachable` berkorelasi dengan kegagalan perangkat menemukan rute/ARP lokal (masalah lapisan fisik/lokal), sedangkan `Request Timed Out` berkorelasi dengan paket yang berhasil dikirim ke gateway namun tidak ada jawaban balik dari tujuan.  
B. Kedua pesan eror tersebut memiliki makna yang identik dan hanya disebabkan oleh kabel LAN yang lepas.  
C. Pesan `Request Timed Out` pasti disebabkan oleh router yang terbakar, sedangkan `Destination Host Unreachable` disebabkan oleh salah DNS.
